# new-index3 首屏以下重设计方案（草案 v1）

> 范围：首屏 Inkeys 艺术字及其绘制动画**不动**；重做首屏以下的功能介绍、展示图与下载区，并统一设计语言。

## 0. 诊断：现在为什么不够惊艳

| 问题 | 位置 | 原因 |
|---|---|---|
| 图小、受限 | `FeaturePager.vue` 舞台 `min(840px, 66vw)`，并且还要和文字一起塞进一屏（`fitPage` 会再缩小） | 图是"文章配图"，而不是"展品"；2880px 的原生渲染只显示到约 840px |
| 没有记忆点 | 每页都是"圆角图 + 居中衬线标题 + 三行字"，五页完全同构 | 节奏单一，没有任何一页敢于占满屏幕 |
| 下载区不协调 | `ReleaseSection.vue`：#dfe9e6 圆角卡片 + 玩具化的桌面壁纸 + Ui3Bar + 一颗胶囊按钮 | 三种材质（纯色卡片、渐变壁纸、产品 UI）挤在 840px 里；按钮是通用 SaaS 胶囊，和产品工具栏的语言无关 |
| 产品本身的卖点（原生渲染的墨迹质量）没被讲出来 | 全站 | 墨迹被压平在一张 JPEG 式的成品图里，用户无法感知"这些是 Inkeys 实机画出来的" |

## 1. 设计主张：**「透明图层」—— 网页就是一块被 Inkeys 书写的屏幕**

Inkeys 的本质是"在任何画面之上叠一层墨迹"。所以整页的设计语言就是**图层**：
底图（课件、桌面、白板、PDF）是安静的、去饱和的；墨迹是唯一的高饱和色彩，并且总是**浮在上面、可以被拎起来看**。

- 唯一的大胆之处：**巨型墨迹 + 图层拆解**。其余排版、控件全部安静、克制。
- 颜色只来自墨迹本身：彩虹色只出现在"墨迹"上（字标、笔画、转场），界面控件一律用中性色和产品工具栏的材质。
- 所有"介绍文字"都以**批注**的形式出现：细墨线引出 + 手写感的标注位置，而不是卡片。

## 2. Token

### 色彩（浅色 / 深色）

| 名称 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| Board 板面 | `#F3F6F8` | `#0E1418` | 页面底色（冷灰白，取自白板点阵底） |
| Grid 点阵 | `#C9D3DB` | `#24303A` | 板面点阵、细线、分隔 |
| Slate 板墨 | `#18222B` | `#E6ECEF` | 正文与标题 |
| Teal 交互 | `#286A71` | `#9ACBC1` | 焦点、链接、当前页（沿用现有，保持连续） |
| Ink Spectrum 墨谱 | `#058A98 → #89C35B → #EBC50B → #FFA414 → #F96254 → #E8597F → #B370BD → #4A79C9` | 同 | **只用于墨迹**：巨型笔画、标注引线、悬停描边。取样自 `wordmark-inkeys.png` |

### 字体

- 品牌拉丁词：`DM Serif Display` Italic（与首屏一致，已在用）。
- 中文标题：`Noto Serif SC` 600，尺寸大幅放大：区块标题 `clamp(40px, 6vw, 96px)`，与图片同等分量。
- 正文：系统无衬线（沿用主题），17–19px，行长 ≤ 32 个汉字。
- 标注文字（悬停说明）：无衬线 14–15px + 一行等宽的"出处"小字（例如 `Inkeys-draw · 原生离屏渲染`）——这里的等宽字体表达的是"这是真实渲染数据"，不是装饰。

### 版式

- 展示图一律**通栏**（`100vw`，最大 1920px），高度接近一屏；文字不再与图片挤在同一屏内，而是在图片之前/之后独立占位，或作为图上的批注。
- 文字左对齐，固定在 8vw 起始的窄栏中；只有收尾的下载区居中。
- 去掉"每页一张圆角卡片"的结构。圆角只保留在产品 UI 自身（工具栏、按钮）上。

## 4. 关键模块细节

### ② 巨型墨迹转场

- **直接复用首屏已有的 `softPen.ts` 软笔渲染器**画这一笔，而不是 SVG 描边，这样转场的笔锋、粗细变化和首屏字标是同一套引擎画出来的——本身就是在展示产品。
- 路径：一条从左下起笔、横穿视口、在右侧收笔回钩的大 S 形曲线，笔宽约 18vh，颜色沿墨谱渐变。
- 播放方式：随滚动推进（scroll-scrubbed），往回滚会"倒写"；`prefers-reduced-motion` 时直接显示完整笔画。
- 只此一处大型非交互动画，其他区块不加淡入上浮。

### ③ 概览图层拆解（核心）

用 `inkeys3-showcase-assets/overview` 拆出这些图层（自下而上），每层都有悬停批注：

| 层 | 来源 | 悬停批注（草拟） |
|---|---|---|
| 桌面壁纸 + 任务栏 | `backgrounds/desktop-wallpaper.jpg`、`desktop-taskbar.webp` | 屏幕批注：在桌面任意窗口之上书写 |
| PPT 课件 | `backgrounds/ppt-slide.png` | 跟随 PowerPoint / WPS 放映，逐页保留批注 |
| PPT 批注墨迹 | `native-ink/ppt-slide-ink.png` | 软笔、荧光笔、箭头 —— Inkeys 渲染管线输出 |
| 白板底 | `native-ink/board.png` | 多页白板，点阵画布无限延展 |
| 白板手写 | `native-ink/board-ink.png` | 原生离屏渲染的手写公式（Inkeys-draw 718b0eb） |
| 白板图形 | `native-ink/board-shapes.png` | 双曲线、坐标轴、虚线 —— 图形工具绘制 |
| 字标 Inkeys | `backgrounds/wordmark-inkeys.png` | 首屏同款软笔字标 |
| 工具栏 + 两侧分页 | `ui-light|dark/toolbar.png`、`ppt-pager.png`、`board-pager.png` | 主工具栏：可打断的回弹动画、动态光影 |

交互：

- 桌面端：`perspective` + 每层 `translateZ` 与 `rotateX(≈52°) rotateZ(≈-8°)`，由滚动进度插值；各层位置都按原画布坐标的百分比定位，合成态与成品图逐像素一致。
- 悬停：该层 `translateZ` 抬起并放大到 1.06 倍，加一圈墨谱色的柔光描边；其他层透明度降到 0.25；批注从该层的锚点用一条手绘墨线（SVG，描边动画 300ms）引出到旁边，内容为标题、一句说明和一行出处。
- 键盘：每层都可以用 Tab 聚焦，效果与悬停相同；`Esc` 退出。
- 触屏：不做 3D 拆解，改为合成图上的热点，点按后从底部弹出批注。
- 降级：减少动态效果时只显示合成态，热点仍可用。

### ④ 笔触

- 五个墨迹层（`handwriting / highlight / brush / pattern / geometry`）叠在 `background-master.png` 上，用从左往右的遮罩擦出，模拟"写上去"，随滚动依次出现。
- 图例与图层双向联动：悬停图例时高亮对应图层，悬停图层时高亮对应图例。

### ⑥ 下载区

- 去掉圆角卡片和渐变桌面壁纸。
- 产品工具栏放大到约 60vw，作为视觉主体，并保留现有的视差倾斜。
- 下载控件做成工具栏同材质的按钮组（同圆角、同阴影、同图标加文字的结构），主按钮用 Teal 实色；与工具栏放在同一行或紧贴其下，从视觉上"长"在产品 UI 上。
- 次级按钮：GitHub「为仓库点亮 Star」（见第 7 节）。

## 5. 实现要点

1. **素材预处理脚本**（新增，放在 `scripts/` 下）：从 `inkeys3-showcase-assets` 读取图层 → 按 alpha bbox 裁切 → 导出 `webp`（1440 / 2880 两档，分浅色和深色）→ 输出 `layers.json`（每层的 x、y、w、h 占画布的百分比、z 序与批注文案键）。
   概览图的斜切分区（`scene.json` 的 `splits`）用 CSS `clip-path: polygon()` 还原；PPT 课件在画布中的位置与缩放需要从合成脚本中读出（`inputs/scene.json` 的 `slide` 段）。
2. 新组件：`InkStroke.vue`（②）、`LayerStack.vue`（③④ 共用，接收 `layers.json`）、`ReleaseFinale.vue`（⑥）。`FeaturePager.vue` 的整页吸附翻页改为 sticky + 滚动进度驱动（见问题 1）。
3. 性能：图层按需懒加载，只在进入视口前一屏开始加载；3D 期间只动 `transform` 和 `opacity`；离开视口后暂停软笔渲染。
4. 深色主题：墨迹层浅深共用；UI 层与板面取 `ui-dark`。白板底在深色下是否另有底图需要确认（成品 `overview-dark.png` 存在，但 `native-ink/board.png` 只有一张）。

## 6. 风险

- 3D 拆解在低端触屏大屏（教学一体机）上可能掉帧 → 用检测 + 降级策略处理。
- 总图层体积预估在 3–5 MB（webp），需要严格懒加载。
- 墨迹转场使用 `softPen` 实时渲染，会占用一部分 CPU/GPU；首屏本身已在绘制，需要错峰运行。

## 7. 已确认的决策（2026-11-09）

1. **翻页机制**：去掉整页吸附翻页，改为 sticky + 滚动进度驱动（往回滚会倒放）。
2. **巨型墨迹**：复用 `softPen.ts` 实时渲染，与首屏字标使用同一套引擎。
3. **性能 / 界面 / 兼容**：作者会补充原生图层素材。先按 `LayerStack` 的图层展示预留位置，`layers.json` 的结构与概览、笔触一致，素材到位后只需替换数据。
4. **下载区**：「下载 Inkeys3」主按钮，加一个 GitHub 次级按钮，文案类似「为仓库点亮 Star」，链接到 `https://github.com/Alan-CRL/Inkeys`。两个按钮都采用工具栏同材质。不加版本号和系统要求信息行。
