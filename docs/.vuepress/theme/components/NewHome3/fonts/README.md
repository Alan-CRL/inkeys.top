# Release title font subset

Locally hosted Archivo Black WOFF2 subset fetched from Google Fonts on 2026-10-22. It uses the genuine Regular (400) face, which is intrinsically heavy.

`archivo-black-release.woff2` contains the glyphs in `Inkeys3`. The adjacent `archivo-black-release-OFL.txt` retains the original SIL Open Font License. Source: https://github.com/google/fonts/tree/main/ofl/archivoblack.

Reproduce through Google Fonts CSS2 with `family=Archivo+Black&text=Inkeys3&display=swap`, requesting a modern browser WOFF2 response, and download the returned font URL. The website loads only the local asset. Extend the subset if the title text changes.
