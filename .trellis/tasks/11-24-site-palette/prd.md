# 全站配色与顶栏统一

## Goal

让首页以外的所有页面使用首页 / UInk 首页的配色风格，营造“无界感”；顶栏与首页统一。Plume 的其他控件照常使用。

## Requirements

### 配色

- 背景、文字改用首页令牌（浅：底 `#ffffff`、表面 `#f5f5f5`、正文 `#121212`；深：底 `#0f0f0f`、表面 `#1b1b1b`、正文 `#f2f2f2`），通过覆盖 Plume 的 `--vp-c-*` 等变量实现。
- 品牌色全站换成首页强调色（浅 `#006a63` / 深 `#58ffec`），链接、侧边栏选中项、大纲高亮、按钮等随之变化。

### 无界感

- 侧边栏与内容区同一底色。
- 去掉（或改成与底色同色）这些分割线：顶栏底边、顶栏与侧边栏之间的竖线、侧边栏右边、手机页内导航（local nav）上下边、页脚上边。
- 正文内部用于阅读结构的线（表格、代码块、提示块、页内大纲左侧线、上一页 / 下一页上方线）不在本次强制去除范围，实现时按观感决定，保证可读。

### 顶栏

- 全站顶栏学习首页：品牌字号字重、文字链接颜色、“下载”文字链接由右侧“下载”按钮替代、深浅色圆按钮与“更多”菜单（`NavActions.vue`），去掉顶栏分割线。
- 首页以外的页面都保留搜索；搜索框外观改成与首页按钮同一风格（圆角、表面色底、无边框）。首页仍不显示搜索。
- Plume 自带的深浅色开关、社交图标在桌面顶栏收起；手机汉堡菜单里保留。

### 兼容

- 首页、UInk 首页现有效果不变；两处重复的令牌尽量收敛到一处。
- 不复制或替换 Plume 组件文件。

## Acceptance Criteria

- [ ] 文档页、版本列表页、下载页、社区 / 链接页、UInk 规范子页在浅 / 深色下背景、品牌色与首页一致。
- [ ] 侧边栏与内容区之间、顶栏下方看不到分割线。
- [ ] 提示块、代码块、表格、搜索弹窗、侧边栏选中项在新底色上可读、层次清楚。
- [ ] 顶栏右侧在所有页面都是：搜索（首页除外）、下载按钮、深浅色按钮、更多菜单，样式一致。
- [ ] 从首页进入其他页面时顶栏不跳变。
- [ ] 手机宽度下顶栏与汉堡菜单正常。
