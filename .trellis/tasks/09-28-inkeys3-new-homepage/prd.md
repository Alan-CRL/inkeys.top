# Inkeys3 新主页

## Goal

为 Inkeys3 发布打造一个超出 Plume 预设能力的全新主页。完成前放在 `/new-index` 测试，现有 `docs/index.md` 保持不变。本阶段重点是样式、交互和动效框架；正式文案与高清素材（官方渲染图、动图）后续由程序渲染后填入。

## Background

- 站点：VuePress 2.0.0-rc.30 + vuepress-theme-plume 1.0.0-rc.204，已安装 `three`、`postprocessing`、`@vueuse/core`。
- Inkeys3 的 UI3 浮动栏与 Draw3 画笔引擎事实见 `research/inkeys3-ui3-draw3.md`。
- 参考风格：极简现代（参考图 1、2），有层次和大圆角而非完全平面（参考图 3），软件深色主栏截图（参考图 4）。

## Decisions

- 首屏采用融合方案：1:1 复刻 UI3 主按钮 + 主栏（HTML/CSS）。悬停按钮时，上方展示区切换到对应功能介绍；空闲时自动轮播。
- 保留 Plume 顶部导航栏、页脚和深浅色切换；页面主体全部为自定义 Vue。
- MVP 不使用 Three.js/WebGL，以保证加载速度和 GPU 开销。

## Requirements

- R1 路由：`/new-index` 可访问，使用 Plume 导航栏与页脚，无侧边栏、无大纲，带 `noindex`。
- R2 主题：完整支持浅色与深色，跟随 Plume 切换；强调色使用 UI3 Accent。
- R3 首屏：大标题 + 副标题；功能展示卡（大圆角、带媒体槽位）；UI3 主栏复刻；“了解更多”平滑滚动到详细介绍；下载按钮。
- R4 主栏复刻：主按钮（超椭圆 Logo）+ A1（选择、软笔、形状、橡皮、撤回、清空）+ 更多、设置 + A2（白板、定格），尺寸与配色取自 UI3 源码；按下/释放缓动、悬停过渡、跟随指针的边缘光。
- R5 轮播：约 5 s 切换一个功能，当前按钮显示进度；指针悬停在主栏上、标签页隐藏、首屏离开视口时暂停。
- R6 详细介绍（下滑后）：UI3（界面设计、交互、光影、动画）；Draw3 流畅与性能；笔的美化（实时平滑、实时笔锋、压感与模拟压感、墨迹预测）；笔的效果（软笔、硬笔、激光笔、荧光笔，刷子即将推出）；更多功能；下载 CTA。
- R7 素材槽位：所有文案与媒体集中在一个数据文件；未提供媒体时显示风格化占位，后续替换素材不改布局。
- R8 性能：只有首屏进入首屏 chunk，下方区块异步加载；动画只用 transform/opacity；`backdrop-filter` 限制在少量元素；媒体懒加载。
- R9 无障碍：主栏按钮为真实 `<button>`，含 `aria-label`、`aria-pressed`、键盘焦点；`prefers-reduced-motion` 时关闭轮播和指针光效。
- R10 响应式：768 px 以下主栏可横向滚动，布局不溢出；375 px 宽度可用。

## Acceptance Criteria

- [ ] `pnpm docs:build` 成功（SSR 无浏览器 API 报错）。
- [ ] `/new-index` 在浅色与深色下均正确显示，切换主题后配色即时变化（R1、R2）。
- [ ] 首屏可见标题、展示卡、主栏、“了解更多”和下载按钮；点击“了解更多”平滑滚动到详细介绍（R3）。
- [ ] 悬停或键盘聚焦主栏按钮会切换展示内容；空闲时自动轮播，悬停主栏时暂停（R4、R5、R9）。
- [ ] 详细介绍包含 UI3、Draw3（性能、美化、笔效果）、更多功能与下载区块（R6）。
- [ ] 替换 `newHome.data.ts` 中的媒体字段即可显示真实素材（R7）。
- [ ] 375 px 宽度下无水平溢出（主栏自身滚动除外）（R10）。
- [ ] 现有 `/` 首页不受影响。

## Out of Scope

- 替换正式首页 `docs/index.md`。
- 最终文案、官方高清图片/动图的制作。
- Three.js/WebGL 3D 效果（后续可作为增强）。
- 网页内真实绘制体验。
