## 1. 总体架构

继续采用“原生离屏产品层 + 可重建宣传片合成层 + 现有网页播放器”，不引入新视频框架。

```text
feature/shape 原生 fixture / 输入时间轴
  ├─ UI3 Bar / PageControl / Whiteboard
  ├─ Draw3 Ink / Shape / Laser / PenIcon
  └─ revision、状态、参数、帧号、alpha、hash
                    ↓
        sources-redesign/manifest.json
                    ↓
教学背景 + 应用窗口 + 宣传片光标 + 数学符号 + 斜轴镜头
                    ↓
       共享 scene timeline（桌面 / 手机 / GIF）
                    ↓
        MP4 + WebP poster + GIF + verification
                    ↓
       现有 FeatureMedia / FeatureSections 合同
```

### 图层所有权

| 层 | 内容 | 允许的来源与处理 |
| --- | --- | --- |
| 外部环境层 | 浏览器、桌面、PowerPoint/WPS 风格窗口、单摆、原始几何线、网页图标按钮 | 可编写，但必须明确是教学环境；不得冒充 Inkeys 控件或真实 Office 验收 |
| 原生 UI 层 | 主栏、分页、白板主题、真实面板和选中态 | 生产 UI3/Whiteboard 离屏渲染；保持共享画布锚点，不逐帧 trim |
| 原生绘制层 | 自由笔、Shape、Laser、PenIcon | 生产 Draw3 渲染与固定输入；保存预览/提交/瞬态生命周期 |
| 输入指示层 | 图一风格现代圆角箭头、移动光晕、路径 | 宣传片专用高分辨率视觉；与原生输入共用事件时间，不宣称系统默认光标 |
| 教学符号层 | `mg`、`T`、`Fₜ`、安装/插件禁止符号、链环、应用标识 | 跨语言符号与图标；不添加需翻译句段，不冒充软件弹窗 |
| 镜头/转场层 | 斜向取景、窗口前后景、三色斜分、页面斜向平移 | 只变换允许的背景/合成层；不得改变原生控件比例或伪造产品能力 |

## 2. 模板与数据合同

### 2.1 保留与升级

- 保留 `storyboard.json`、`render.py`、`native/`、`verify.py` 和现有八个 scene ID。
- 新分镜使用独立版本，不让旧 `schemaVersion=1` 的全局 7 秒限制新内容。
- 新版每段拥有独立 `durationMs`、`fps=60`、`shots`、`actions`、`transition`、`anchors`、`required` 和首末帧定义。
- 桌面、手机和 GIF 共用动作时间，不复制三份分镜；profile 只拥有尺寸、fps 变体、取景框和排版锚点。
- `FeatureMedia` 继续读取每段 `durationMs`；不改 scene ID 或网页媒体目录合同。

### 2.2 建议文件职责

- `storyboard.json`：完整镜头、输入事件、时刻、场景依赖和构图；不藏业务状态硬编码。
- `render.py`：时间轴调度、原生层合成、profile 输出、编码和 manifest。
- `scenekit.py`：共享窗口、单摆、现代光标、斜轴 easing、数学符号和几何背景构件；避免在八幕重复实现。
- `native/`：仅负责生产像素、真实输入和 provenance，不承担教学背景或宣传片光标。
- `sources-redesign/`：新原生输入，与旧 `sources/` 隔离。
- `build/redesign-*`：代表帧、试片、日志和临时输出；公开目录只接收验收后的完整成品。

`scenekit.py` 是唯一计划新增的共享合成模块；不预先搭多层框架。如果实际实现可以更小，优先保持简单。

## 3. 视觉、光标和转场参数

### 3.1 焦点纪律

每个时刻只有一个主动作：

1. 指针移动时，背景只保留必要的低强度运动，镜头不动。
2. Down/Up 时，指针停稳，使用原生按压与释放帧。
3. 功能结果出现时，指针停止或离开，不立刻开始下一动作。
4. 最终结果保留约 0.8–1.2 秒；复杂受力图保留约 1.5 秒。

主栏在每段第一帧已经就位。禁止旧版 `22*(1-settle)` 上浮、无业务原因的淡入淡出和为了特写淡出全部上下文。

### 3.2 现代鼠标箭头（宣传片层）

- 重新绘制高分辨率圆角箭头，不能放大用户提供的低清参考图。
- 深青填充、浅色细描边；圆角连接，比例接近图一但不宣称逐像素复刻。
- 移动时显示克制青绿光晕；静止约 150ms 后收敛。
- Down 时光晕收缩，配合真实按钮反馈；Up 后不扩散点击圆环。
- 路径约 0.32–0.42 秒，短距离、轻微弧线、末端减速；不进行永续漂移。
- 用于所有画布外操作，以及选择/穿透状态下的画布内操作。

### 3.3 PenIcon 与工具光标

- 自由笔优先采用真实 Mouse Drawing 输入，使 PenIcon 在接触绘制时可见。
- 浅底使用深石墨外轮廓，保留当前笔色填充；建议最终像素外轮廓约 1.25–1.5px。深底使用对比浅轮廓。
- 深边属于 harness/宣传片视觉调整，必须在 provenance 记录，不能写成已有用户配置。
- 笔尖左上热点与墨迹样本一致；禁止笔迹从光标中心或笔尾出现。
- Shape 使用真实 Shape 光标和 Down/Move 预览、Up 提交；Laser 使用真实 core/halo，不把 Laser 当成持久笔。
- 光标越过画布边界时按工具/穿透状态即时切换，不让两种光标互相淡入或同时漂浮。

### 3.4 颜色与文字

- 原始课件图形：灰黑。
- 新增可见辅助线：青蓝。
- 隐藏边/构造虚线：橙黄。
- 白板保留现有白色空白、米白点阵、墨绿网格；激光用真实白核心和足够对比的彩色外辉光。
- 无新增中文/英文句段。真实 UI 标签与页码来自原生 i18n；教学层只使用 `mg`、`T`、`Fₜ` 等跨语言符号。

### 3.5 统一斜轴转场

- 方向沿 `/`：下一内容从右下向左上进入，返回沿同轴反向。
- 时长约 0.32–0.44 秒，使用快速到位、末端减速的非线性 easing。
- 位移是短距离构图变化，不做整屏甩动或主栏回弹。
- 转场只发生在信息空间改变时；书写、按下、定格提交期间不使用。
- 产品指令、页码和原生状态按真实时机更新；斜向平移仅属于宣传片层。
- 同一段不连续使用多次推拉；优先保持全景，只有笔尖/受力细节需要时才斜向移近。

### 3.6 清晰度与输出

- 以 2 倍尺寸绘制外部环境、现代光标和符号，再 downsample 到最终 1440×640 / 720×720。
- 原生控件继续使用高倍率透明捕获，不能直接放大旧低分辨率整张视频。
- 主时间轴 60fps；UI 原生动画按真实采样导出，不套镜头 easing。
- README GIF 沿用 960×426 / 15fps 和共享时间轴，不能从另一套动作重新制作。
- 每段定义首帧 poster 候选和最终阅读帧；接触表按 scene 范围命名，避免部分导出互相覆盖。

| A3-S6 6.0–6.8 | Shape 工具、真实工具光标、已预设 Dashed 构造工具 | 指针完成真实 Shape 点击；录制前预设线型，不演笔迹自动变虚线 |

## 7. 移动端、poster 与首尾帧

- 移动端采用同一世界坐标和事件时间，按当前动作选择浏览器内容区、受力图、当前活动窗口或白板局部；不是把桌面缩成完整小图。

- C1 手机端仍要看见同一激光波浪连续跨区；可调整三区域宽度和波浪振幅，但不能拆成三次 contact。

- C1/C2 的相邻首末帧需对齐；其他场景手动单独选择时也能独立理解。

## 8. 验证设计与回滚

### 原生验证

- 当前分支/revision/工作区状态写入 provenance；旧 `Inkeys-draw@afee2f` 与新 `feature/shape@d060e39` 不混为同一来源。
- Shape 校验预览、Up 提交和最终文档像素；Dashed 连续路径、圆锥后侧弧和箭头实线头部有代表帧。
- Laser 校验一次 contact、Up、Hold、Fade、完全消失；无持久墨迹。
- PenIcon 校验热点、深边、浅/深底对比；现代箭头单独标为 editorial。
- 所有透明帧保持共享锚点和 straight-alpha，禁止黑边、逐帧抖动和错误双层预乘。

### 视觉与媒体验证

- 先审八幕代表帧，再审 A3/B1/C1 运动试片，再批量渲染。
- 逐镜头检查：目标是否唯一、点击因果是否完整、定格瞬间是否锁定、恢复笔迹是否精确、是否出现未授权文字。
- 实际解码检查每段 fps、帧数、时长、尺寸和 hash；GIF 与 MP4 使用同一动作时间。
- 浏览器验证真实 H.264 播放、暂停、隐藏/离屏恢复、手动选择、ended、换源续播、poster 和 320–599px 无横向溢出。
- 最终执行 `pnpm docs:build`，再发布 `public/feature-media`；若涉及 123pan 外链，提醒同步更新。

### 回滚

- 旧 `sources/`、旧公开 MP4/poster/GIF 和旧 storyboard 在新成片验收前不覆盖。
- 新导出的中间文件和预览放 ignored `build/`，正式 sources 与公开成品分开提交边界。
- native 适配出现锚点冲突、并发修改或导出失败时停止，不伪造替代素材；恢复原字节后再决定下一步。
