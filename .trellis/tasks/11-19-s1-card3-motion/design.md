# S1 第三张卡片“PPT 演示”：设计记录

工程在 `media/nh3-remotion/src/cards/slide-show/`，合成名 `S1-SlideShow-Light` / `-Dark`（预览 `Preview-SlideShow-Light-zh` / `-Dark-en`）。只做到 Remotion Studio 预览。

## 1. 重做的原因（2026-11-22）

第一版（石拱幻灯片，源码备份在 `media/nh3-remotion/out/slide-show-v1/`，不入库）用户评价“分镜和动画都比较意义不明”。问题：开场是插图的大特写，看不出是幻灯片；两页画的是同一座拱，擦除转场读不出翻页；推近后分页栏出画；受力箭头要懂结构才看得懂；幻灯片只占卡片中间一小块。

用户认可的方向：整页横向推走、墨迹跟着页走；并提示加入激光笔——放映时先用激光笔圈画，在别处用另一种颜色标记时激光渐渐隐藏，之后才翻页并做别的标记。

## 2. 这张卡片讲什么

放映时讲的人有两种笔：激光笔只是“看这里”，过一会儿自己消失；普通的笔写下的留在这一页上，翻走再翻回来还在。

- 两页自制英文幻灯片，灰阶：第 1 页大标题“Spring launch”加三步进度线（Plan、Build、Ship），第 2 页柱状图“Sign-ups”。版式差得远，缩到卡片大小也分得清翻没翻页。
- 构图和前两张一致：放映画面铺满屏幕框，屏幕向右伸出卡片，分页栏骑在底边上。不画主栏。
- 激光用红色 `#FF1000`（软件默认）。笔在软件里默认也是红色，为了分得开换成调色板里的蓝：浅色版 `#326ED9`，深色版 `#4EA1B7`（前者在深色幻灯片上偏暗）。

## 3. 分镜（60 帧每秒，547 帧，约 9.1 秒）

帧号由各段时长推算，以 `Card.tsx` 导出的 `SLIDE_SHOW_TIMELINE` 为准。

| 帧 | 画面 | 镜头 |
| --- | --- | --- |
| 0–30 | 干净的第 1 页 | 全景，随即推向进度线的最后一步 |
| 30–78 | 激光笔圈住“Ship” | 特写，1.8 倍 |
| 78–106 | 激光满亮停留；手移向标题 | 拉开到同时装得下标题和激光圈的机位，1.34 倍 |
| 106–163 | 蓝色的笔圈住标题；第 138 帧起激光开始变淡 | 不动 |
| 163–186 | 激光熄灭（第 186 帧） | 第 166 帧起拉向全景 |
| 204–242 | 第 208 帧起 Next 被按下，第 216 帧页码变 2；第 1 页带着圈滑走，第 2 页滑入 | 全景；第 222 帧起推向柱状图 |
| 256–325 | 沿柱顶画一条上升的箭头，再写箭头尖 | 1.34 倍，极慢地继续推近 |
| 351–423 | 拉回全景；Previous 被按下，第 397 帧页码变 1；第 1 页带着圈滑回来，激光没有回来 | 全景 |
| 407–505 | 停在仍然在那里的圈上 | 缓慢推向标题，1.55 倍；这是全片停得最久的画面 |
| 505–547 | 墨迹淡出，回到干净的第 1 页 | 拉回全景，接上开头 |

## 4. 用到的软件事实

来源：`research/codex-slideshow-survey-result.md`、`research/codex-laser-survey-result.md`（gpt-6.2-sol 只读调查，`Inkeys-draw` 的 `refactoring/drawpad-ui`）。关键结论由 Claude 在源码里核对过。

| 事实 | 在片子里怎么用 |
| --- | --- |
| 放映左下角分页栏：拖动柄、Previous、页码（上下两行）、Next，主体 240×80 | 重新离屏导出（`native-slideshow/`） |
| 第 2 页（共 2 页）时右键仍是 Next，进入结束屏后才变 End show | 两页的放映成立；旧工程借来的分页栏图画的是 End show，已过时，不再使用 |
| 按下按钮是缩到 0.95 加一层压暗，没有水波 | 只做压暗，不加水波；不缩放（镜头在动时缩放的边缘会有接缝） |
| 每页墨迹独立保存，翻回去恢复；页面立即切换 | 横向推走是剪辑上的转场；页码在按下的那一帧更新 |
| 激光笔四层材质：外层漫反射（向外 5 DIP、平方衰减）、实体壳（笔色，默认 5 DIP）、内散射环、白芯（D/3） | `Laser.tsx` 用几层描边加模糊近似，漫反射略亮于原生 |
| 激光寿命：最后一道抬笔后满亮 1.0 秒，再 0.8 秒整条淡出，曲线 `1 − t²(3 − 2t)`，长度和宽度不变 | 照这两个取值和这条曲线做 |
| 激光不进撤销历史、不保存到页面，翻页即清空 | 翻回第 1 页时只有圈，没有激光 |
| **切到别的笔的那一刻，还亮着的激光被立即清掉**（`Draw3.DrawingController.cpp` 的 `synchronizeLaserResources`） | **片子里没有照做**：按用户的要求，激光在笔写别处的时候渐渐熄灭。要改回和软件一致，把 `CIRCLE_AT` 排到 `LASER_GONE` 之后 |
