# new-index3 S1 卡片动态展示（Remotion）

## Goal

用 Remotion 为 `/new-index3` S1 的三张卡片制作循环播放的动态展示，浅色、深色各一版。第一步只做“屏幕批注”一张，用来确定风格和制作流程；另外两张（PPT 演示、自由白板）在这一张通过后再做。

同时建立一个独立、方便后期修改的 Remotion 工程，并把制作经验写进 `.trellis/spec/`，供之后 S2 等区块的视频使用。

前置任务：[内容规划](../11-16-new-index3-content-plan/content-plan.md)、[设计语言与布局](../11-16-new-index3-design-system/design.md)。

## Requirements

用户提出的要求（2026-11-16）：

- R1 先只做“屏幕批注”一张卡片。
- R2 视频铺满整张卡片，卡片不再有单独的标题底色区；画面要给压在左上角的标题和一句话留出位置。
- R3 浅色、深色各一版。画面里不放说明文字；界面文字统一用 en-US。
- R4 主栏如果出现，必须是 en-US、选择与穿透合并式；绘制状态、主题深浅可以自由设置。
- R5 建立独立的 Remotion 文件夹，素材整理清楚，方便后期修改。
- R6 制作经验写进 Trellis 目录。
- R7 整体风格符合网页的设计语言（“纯净”）；参考用户提供的 Grok 宣传片（白底、大留白、界面局部特写、动作少而慢）。
- R8 要有小创意：画面里有一个“假边框”，主体越过它（参考 WorkBuddy 海报）。
- R9 注意细节：布局、文字、动效。
- R10 软笔要体现实时笔锋，粗细随书写速度变化，样子和软件里一致。这一项用户要单独审阅；达不到就改用硬笔。
- R11 笔迹路线要像真人写的。样张里收笔向上挑的写法不自然，成品里不能出现。
- R12 墨迹必须避免四类问题（用户 2026-11-16 补充）：
  1. 路径错位：墨迹要和背景里被标记的东西对在同一个位置（圈住的就是那个标题、那颗行星，荧光笔盖住的就是那句话）。
  2. 笔锋不正常：软笔的笔锋是实时的，书写过程中一直跟在笔迹最前端。
  3. 颜色不合适：墨迹颜色在浅色、深色两版里都要清楚、好看。
  4. 匀速书写：书写过程的速度要像人写的，有快有慢。
- R13 窄屏下卡片的比例要处理好，保证视频显示正确（不裁掉主体，文字不压到画面上）。

本轮确认的决定：

| 项目 | 决定 |
| --- | --- |
| 创意方向 | A“一笔出框”：卡片下方一块圆角的假屏幕，示例内容留在框内，墨迹和主栏越过边框 |
| 内容节拍 | 一个循环三拍，约 8.0 秒（最初 10 秒，收紧到 6 秒后又按用户意见放慢书写、加长停顿，并推后定格）：网页＋软笔圈画 → PDF＋荧光笔 → 视频＋定格后圈画 |
| 题材 | 太阳系与火星（网页标题 The red planet、PDF 讲火星公转、视频是行星绕太阳转） |
| 界面来源 | 混合：主栏用软件原生离屏导出的静态图层；墨迹在 Remotion 里按软件的规则绘制 |
| 墨迹颜色 | 软笔红色 `#FF1000`（软件默认）；荧光笔黄色 `#FFC510`，不透明度 35% |
| 视线引导 | 指针全程在场：画布上是软件的“画笔指针（高亮）”，主栏上是鼠标箭头；移动走弧线，点击时按钮夸张按下并扩出一圈水波，不加粒子 |
| 样张与分镜 | 用户已确认，见 [design.md](./design.md) 和 `styleframe/styleframe.png` |

## Constraints

- 不使用滚动驱动的动画；视频进入视口播放、离开暂停；系统开启“减少动态效果”时显示静态封面。
- 视频里不出现客户、个人或内部数据；示例内容全部自制。
- 不修改软件仓库的源码（离屏导出用的临时适配按现有流程挂载并按字节还原）。
- 遵守 `.trellis/spec/frontend/native-media-guidelines.md` 的原生导出约定。
- 本任务不包含 PPT 演示、自由白板两张卡片，不包含 S2 的视频。

## Acceptance Criteria

- [ ] `media/` 下有独立的 Remotion 工程，一条命令能渲染出“屏幕批注”的浅色、深色两版成片和静态封面。
- [ ] 成片首尾相接，循环处看不出跳变；时长约 8.0 秒。
- [ ] 画面符合已确认的样张和分镜：示例内容留在屏幕框内，墨迹和主栏越过边框；屏幕里的内容是灰色调。
- [ ] 主栏来自原生导出，en-US、合并式，三种状态（软笔、荧光笔、软笔＋定格）× 深浅色齐全。
- [ ] 软笔的实时笔锋和速度粗细变化经用户单独审阅通过（或按用户意见改用硬笔）。
- [ ] R12 的四项逐条自查通过：每道墨迹与被标记的对象对位（抽帧核对）、书写中每一帧最前端都有笔锋、两版配色都清楚、速度曲线有快有慢。
- [ ] 从 320 到 1440 的各种宽度下，视频主体不被裁切，三种语言的文字都不压到墨迹和屏幕上。
- [ ] 中文、繁中、英文三种文案叠在视频上都不遮挡画面主体，墨迹不碰到文字。
- [ ] 卡片在 `/new-index3` 上播放成片（浅色、深色自动切换），`pnpm docs:build` 通过。
- [ ] 制作经验已写入 `.trellis/spec/frontend/remotion-video-guidelines.md`。
