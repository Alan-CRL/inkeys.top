# S1 第二张卡片“自由白板”：设计记录

用户于 2026-11-18 把这张卡片的创意交给 Claude 全权决定，要求只做到能在 Remotion Studio 里预览，不渲染成片。
工程在 `media/nh3-remotion/src/cards/whiteboard/`，合成名 `S1-Whiteboard-Light` / `-Dark`。

## 1. 和第一张卡片的区别

第一张卡片（屏幕批注）让指针把软件操作演了一遍，用户评价平淡。原因和结论见 `design.md` 之后的复盘，这里只记这张卡片采用的做法：

- **主角是笔迹，用镜头来讲。** 没有指针，也不去点按钮。
- **有大小对比。** 特写时白板铺满文字区以下的整张卡片，拉远后才露出屏幕的圆角边框。
- **有一个高光时刻。** 镜头跟着笔尖横移，看一笔正弦曲线写出来（弯处慢而粗、直处快而细），然后以收笔处为轴拉远，露出整页。
- **循环的接缝藏在翻页里。** 结尾翻到空白页并推回特写，和开头是同一个画面。

## 2. 用到的软件事实

来源：`research/codex-whiteboard-survey-result.md`（gpt-6.2-sol 只读调查，分支 `refactoring/draw`，`bcc11421`）。

| 事实 | 在片子里怎么用 |
| --- | --- |
| 白板出厂底色 `#123B32`，和软件的深浅主题无关 | 深色、浅色两版的白板完全相同，只有卡片底色不同 |
| 图案默认是空白，点阵是可选项：点距 24、直径 2，深底上是白点、不透明度 0.18 | 用点阵；镜头移动时它提供参照 |
| 深底白板的默认笔色是白色；调色板里有 `#FFC510` | 算式和棱柱用白色，曲线和标注用黄色 |
| 触摸书写时不显示画笔光标 | 不画光标 |
| 函数曲线的形状模板目前不可用 | 正弦曲线是手写的一笔 |
| 立体图形只有描边、等宽、颜色等于笔色；相邻两个面都背向观察者的棱画虚线（实段 4 倍线宽、间隔 6 倍线宽、圆头）；斜投影系数 0.3536；棱柱默认六棱 | `Prism.tsx` 按这些规则重画 |
| 立体图形分两次拖动放置：先定底面，再定高度，两次都有实时预览 | 棱柱先长出底面，停一下，再长出高度 |
| 画布能平移，不能缩放 | 推拉的是整块屏幕（镜头语言），不是在演示缩放功能 |
| 翻页立即切换，没有过渡动画 | 片子里的横移是剪辑上的转场，不代表软件的翻页动画 |
| 白板的主栏是 Move、Soft Pen、Shapes、Erase、Undo、Clear、More、Close；左下角另有分页栏 | 重新做了原生离屏导出（见第 5 节）；屏幕底边骑着分页栏，右边接着主按钮和主栏的开头 |
| 最后一页的右箭头位置是 Add page，点它新建一页；页码立即更新 | 第一次翻页时 Add page 压暗并扩出水波，页码在同一帧从 1/1 变成 2/2 |

## 3. 构图

- 屏幕的位置和第一张卡片相同（left 44、top 204，向右伸出卡片）。
- y = 196 以上留给网页文字，画面不进入。特写时屏幕的边框都在卡片外，白板在这条线以下铺满。
- 镜头始终对准文字区以下那块区域的中心（192, 390）。

## 4. 分镜（60 帧每秒，536 帧，约 8.9 秒）

帧号由各段时长推算，改时长后会自动顺延；下表是 2026-11-18 的取值，以后以 `Card.tsx` 导出的 `WHITEBOARD_TIMELINE` 为准。

| 帧 | 画面 | 镜头 |
| --- | --- | --- |
| 0–10 | 空白的点阵白板 | 特写，2.6 倍 |
| 10–131 | 白色手写 `y = sin x`，约 2 秒 | 跟着字慢慢右移并后退到 2 倍，写完时整条算式都在画面里 |
| 131–145 | 停 0.23 秒，让人读完 | 不动 |
| 145–183 | 第 177 帧落笔 | 落到曲线的起笔处；还差最后一点没停稳时就落笔，移动和书写连成一个动作 |
| 177–264 | 黄色正弦曲线，一笔 1.45 秒 | 跟拍：右移 |
| 248–302 | 曲线收笔 | 以收笔处为轴拉远到 1 倍，露出屏幕边框、上面的算式、底边的分页栏和主栏 |
| 302–328 | 整页停留；第 320 帧起 Add page 被按下 | 不动 |
| 328–354 | 页码变成 2/2，水波；翻到第二页（横移 0.43 秒，带水平动态模糊） | 第 334 帧起推近到 1.6 倍，分页栏和主栏完全退出画面 |
| 364–388 | 六棱柱的底面长出来 | 极慢地继续推近 |
| 397–433 | 棱柱的高度长出来，被挡住的棱是虚线 | 同上 |
| 449–466 | 黄色手写“h” | 同上 |
| 496–522 | 翻到第三页（空白） | 同时推回 2.6 倍特写，第 532 帧到位 |

2026-11-18 用户看过第一版后同意补上界面，并允许自行优化分镜。改动：补上分页栏和主栏；镜头落到曲线起笔处时和落笔重叠；棱柱一拍推得更近（1.5 → 1.6 倍），不让底边的界面露出半截；拉远后的停留从 20 帧加到 26 帧，给分页栏留出被看到的时间。
