# 功能介绍整页翻页

父任务：`09-28-inkeys3-new-homepage`。范围仅限 `/new-index3` 中「Inkeys3 焕新发布」之后、「下载 Inkeys」之前的 5 个主功能介绍（`primaryFeatures`）。

## 背景

此前「下载 Inkeys」下方的细节功能（如「笔速橡皮与快捷修正」）已采用「纯色圆角舞台 + 居中素材框 + 居中衬线标题与正文」的样式。用户希望把这一风格用于上方 5 个主功能，并把纵向长滚动改为整页卡片式翻页。

## 需求

1. 5 个主功能统一为同一种页面样式：上方圆角舞台（内含居中素材占位框），下方居中标题与正文，沿用细节区的视觉语言。
2. 舞台按比例居中缩小，标题与正文字号适当减小，保证常见桌面视口（如 1366×768、1920×1080）中一页能完整显示图片与全部文字，四周留白。
3. 文案保持原样，不增删改（含「规划中：几何工具与智能图形识别」小节与系统支持备注）。
4. 交互：
   - 从焕新发布继续下滑一段后，焕新发布滑出，第 1 页作为整页滑入（带切换动画）。
   - 每页居中显示，图片与文字带浮入动画；视口内只显示当前页，不露出下一页。
   - 继续下滑一段后切换到下一页，共 5 页；第 5 页后继续下滑，恢复普通滚动进入「下载 Inkeys」及后续内容。
   - 上滑时反向切换，第 1 页上滑回到焕新发布。
5. 页码点：
   - 在翻页区间内，右侧竖排 5 个小点，无文字或其他装饰。
   - 当前页的点使用选中色；无鼠标悬停时所有点大小相同。
   - 鼠标悬停时，点按与指针的距离平滑放大（类似 macOS 程序坞，但幅度更克制）。
   - 点击跳转到对应页（带切换动画）。
6. 「下载 Inkeys」及以下（下载卡片、细节功能、更多功能）和焕新发布卡片本身不改。

## 约束

- 不提交、不推送；不改无关文件；保持原编码、换行与代码风格（单引号、无分号、2 空格）。
- SSR / 无 JavaScript 时内容完整可读（退回纵向排列）。
- 保留各功能锚点 `#nh3-feature-<id>` 可用。
- 页码点可键盘聚焦，有可访问名称与 `aria-current`。

## 验收标准

- [x] 1920×1080 与 1366×768 桌面视口下，5 页各自完整显示舞台和全部文字，无裁切、无下一页露出。
- [x] 从焕新发布下滑触发整页切入；第 1–5 页逐页切换，带滑动切换与内容浮入动画；上滑可逆。
- [x] 第 5 页后继续下滑恢复普通滚动，「下载 Inkeys」及以下外观、行为不变。
- [x] 右侧 5 点仅在翻页区间显示，当前页高亮；悬停平滑放大、离开复原；点击跳转。
- [x] 手机（如 390×844）与矮屏（如 1280×600）同样整页翻页，舞台与文字适配视口，内容不溢出、不裁切。
- [x] 卸载时移除全部监听、观察器与动画帧；SSR 输出完整内容。
- [x] 现有 VuePress 构建通过；命令行回归覆盖页码映射与阈值切换。

## 已确认决策（2026-10-29）

- 翻页手感：原生滚动 + 阈值切换 + 吸附对齐（不拦截滚轮）。
- 小屏：手机与矮屏也整页翻页，不退回纵向排列；需保证内容适配视口。
- 切换动画：上下滑动切换（下翻时当前页上滑淡出、新页从下方滑入，上翻相反），落定时图片、标题、正文错峰浮入。
