# KB2670838 安装问题调查（2026-11-25）

## 结论

1. **SHA-1 签名不是问题。** 微软当前提供的 x64 安装包就是 2013 年的原始文件，签名为 SHA-1，Windows 7 SP1 原生支持，不需要事先安装 SHA-2 补丁（KB4474419 / KB4490628）。SHA-2 的问题方向相反：2019 年 9 月以后的 Windows 7 更新只有 SHA-2 签名，系统缺 SHA-2 支持才装不上，与 KB2670838 无关。
2. **下载链接仍可用。** 微软下载中心 id=36805 仍在（页面“发布日期”显示 2024-07-15，但文件未变），直链返回 200。
3. **常见安装失败原因**（按用户遇到的提示归类）见下表。

## 实测证据

直链：`https://download.microsoft.com/download/1/4/9/14936FE9-4D16-4019-A093-5E00182609EB/Windows6.1-KB2670838-x64.msu`

- `curl -I`：`200 OK`，`Content-Length: 11840839`（11.29 MB）。
- 下载后 `sha1sum`：`9f667ff60e80b64cbed2774681302baeaf0fc6a6`，与 Legacy Update 归档、FileHippo 记录的 2013 年原版一致。
- `Get-AuthenticodeSignature`（Windows 11 上执行，仅检查未运行）：
  - Status `Valid`
  - 签名证书 `CN=Microsoft Corporation, OU=MOPR`，颁发者 `CN=Microsoft Code Signing PCA`，算法 `sha1RSA`，有效期 2012-09-05 至 2013-03-05
  - 时间戳证书 `Microsoft Time-Stamp Service`，算法 `sha1RSA`（有时间戳，证书过期不影响验证）
- x86 包（5.63 MB，SHA1 `984b8d122a688d917f81c04155225b3ef31f012e`）未实际下载，按同批发布推断情况相同。

## 安装失败原因

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| “此更新不适用于你的计算机” | 没装 SP1 | 先装 SP1（KB976932） |
| 同上 | 下载的 x86 / x64 与系统位数不符 | 换另一个文件 |
| 同上 | 已经装过 | 用 `get-hotfix -id KB2670838` 确认，无需再装 |
| 同上 / 其他错误码 | 系统更新组件损坏（如 0x80240022） | 系统更新准备工具 KB947821，仍不行只能修复安装系统 |
| “安装程序遇到错误：0x80070422 / 服务无法启动” | Windows Update 服务（wuauserv）被禁用：wusa 通过 Windows Update Agent 安装 msu，服务禁用就失败。常见于精简版、被“优化”过的系统 | 在“服务”里把 Windows Update 启动类型改为手动或自动并启动，必要时一并检查 Windows Modules Installer、BITS；装完可改回 |
| 装完后蓝屏 / 黑屏 | 微软已知问题：部分 Intel + AMD 双显卡笔记本 | 安装 KB2834140，并到电脑厂商官网更新显卡驱动；不得已时卸载 KB2670838 |
