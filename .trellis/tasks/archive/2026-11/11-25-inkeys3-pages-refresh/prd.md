# 下载侧栏、Inkeys3 介绍页与 Win7 兼容页整理

## Goal

整理下载侧栏，把 `/version/inkeys3` 重写成面向用户的 Inkeys3 介绍页，并把 `/win7` 兼容页改成已发布状态下的规范说明，附 KB2670838 下载按钮和装不上时的处理办法。

本任务承接 `11-24-page-copy`（planning）中“为 /inkeys3 写简单介绍”这一项。

## 范围

- 先只改简体中文（用户 2026-11-25 确认）。繁中、英文的侧栏文字和 `docs/zh-tw|en-us/version/{inkeys3,introduction/win7}.md` 译文暂时保持原样；用户对简中满意后，再在本任务内同步繁中与英文（侧栏改名、两页译文），属于第二阶段。
- 侧栏分组只改简中下载侧栏的数据结构；繁中、英文下载侧栏在第二阶段同样调整。不改 CSS。
- 页面地址不变：`/version/inkeys3`、`/version/`、`/version/introduction/win7`（`/win7` 快捷入口）。

## Requirements

### R1 下载侧栏

- “使用条款”与下一项之间留出一段空隙（不画线），做法与版本侧栏相同：用 Plume 侧栏配置分组（带 `items` 的项单独成组），不改 CSS。
- 简中下载侧栏：“Inkeys3 Canary”改为“Inkeys3”，“版本”改为“更新日志”。徽章保留。
- 简中版本侧栏同步改名：“Inkeys3 Canary”→“Inkeys3”，“版本”→“更新日志”。
- 简中更新日志列表页（版本集合）的标题改为“更新日志”。

### R2 Inkeys3 介绍页（`docs/version/inkeys3.md`）

- 标题改为“Inkeys3”，保留 `sticky` 与标签，使其仍置顶于更新日志列表。
- 正文全部清空重写：从“升级与新内容”的角度，用几段话向普通用户介绍 Inkeys3。素材来源：软件仓库 `README_zh-CN.md` 与主页文案。
- 文案遵守网站文案偏好：面向普通用户，不放性能数字，不出现 Draw3、UI3、RTS、ROT、COM 等内部名称或底层术语，不写“将来支持”；简中品牌名写“智绘教Inkeys”。
- 插入原主页画廊的两张图（overview、tools），随深浅色切换。
- 页面底部放一个“立即下载”按钮，跳转下载页，样式与网站按钮一致。
- 删去旧页面中的 Canary 状态、云盘与论坛链接、“下放至 Inkeys2”和“注意事项”列表。

### R3 Win7 兼容页（`docs/version/introduction/win7.md`）

- 删除“Inkeys3 尚未发布 / Canary”版本状态提示。
- 规范全文用语：通顺、统一术语（Windows 7 SP1、KB2670838、64 位 / 32 位），去掉口语化与重复的表述。
- KB2670838 下载链接改成同风格按钮：主按钮“从微软官网下载”，次按钮“云盘备份”。
- 新增“无法安装时”说明，覆盖：提示“不适用”（未装 SP1 / 位数不符 / 已安装）、错误 0x80070422（Windows Update 服务被禁用）、其他错误（系统更新组件损坏），以及双显卡笔记本装后蓝屏 / 黑屏（KB2834140 + 更新显卡驱动）。
- 说明更新包签名 Windows 7 自带支持，无需先装 SHA-2 补丁（依据见 `research/kb2670838.md`）。
- 底部“一些杂物”提示保持原样（用户确认不动）。
