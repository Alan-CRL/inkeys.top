# 技术设计

## 1. 总体结构

右侧画面不是一张图，而是网页里叠起来的几层。这样每一层可以单独出场，深浅色和以后的语言替换也只换对应的那一层。

```
.nh3-scene-media（纯色面板，裁掉伸出边缘的部分）
└─ .nh3-stage（按面板宽度等比缩放的坐标系）
   ├─ 内容层   网页绘制（白板＝圆角板面＋点阵；后续的报告、幻灯片同理或用图片）
   ├─ 墨迹层   InkeysRenderer 输出的透明图，1–3 张，叠在内容层上，随内容层一起定位
   └─ 界面层   InkeysRenderer 输出的界面透明图（主栏、翻页控件、属性面板），各自一张
```

- 各层用百分比定位和定宽，面板宽度变化时整体等比缩放，不靠 JavaScript 计算。
- 面板保持现有 16:10；内容层故意大于面板，右侧和下侧伸出后被面板圆角裁掉。
- 面板底色每张卡片一种柔和的颜色，深浅色各一个值，写成 `home.css` 里的变量。

## 2. 素材生产

源文件放在 `media/nh3-scenes/`（新目录，不进站点构建）：

```
media/nh3-scenes/
  build.py                 逐个场景 validate → plan → render --at，再裁剪、转 WebP、写 manifest
  board/ink-figure.json    场景模板（颜色用占位名，build.py 按主题替换）
  board/ink-notes.json
  board/ui-bar.json  …
  out/                     渲染中间产物（git 忽略）
```

- 墨迹：`text` 元素写英文、数字和数学符号；`path` 元素画图形、辅助线、圈、箭头、下划线；荧光笔用 `highlighter`。`canvas.dpi = 96`，固定 `seed`，`jitter` 0.3–0.5，笔宽约为字号的 1/12。`durationMs` 设大，用 `plan` 确认 `totalMs` 小于它，再 `render --at`。
- 墨迹画布按面板 2 倍像素设计（约 1600 px 宽），保证高分屏清晰；小字的字号不低于画布 28 px，低于这个值小写字母的圈容易糊。
- 界面：`ui` 元素，`locale: en-US`，深浅色各渲染一次；用 `geometry.jsonl` 的 `bodyRect` 裁掉多余透明区，保留阴影。
- 成品：`render` 的 `frames/f000000.png`（直通 alpha）→ Pillow 转有损高质量 WebP（带 alpha）→ `docs/.vuepress/public/new-index3/s2/<card>-<layer>-<theme>.webp`。`still` 只用于预览。
- 深色：同一份场景模板换一组墨迹颜色（主墨近白、强调色提亮）和 `theme: dark` 的界面，几何完全一致，两套图可以原位互换。
- `build.py` 用 `python3` 运行；渲染器只读调用，不改它的仓库。

## 3. “教室与白板”的内容（样张）

一道完整的立体几何题，数值自洽：正四棱锥 P-ABCD，底面边长 6，高 PO = 4。

- 图形（左上）：棱锥，看不见的棱用虚线；底面对角线交于 O；高 PO；BC 中点 M，连 OM、PM；直角符号；字母 P A B C D O M；边上标 `6`、`4`。
- 推导（右侧，小而密的多行）：`OM = 3`、`PM = 5`（由 3、4、5 得出）、`S = 4 x 1/2 x 6 x 5 = 60`、`V = 1/3 x 36 x 4 = 48`。
- 旁注：右下一个单独画出的直角三角形 POM，三边标 3、4、5；红笔圈出图里的三角形并用箭头连到它；答案下一道荧光笔；蓝笔画辅助线。
- 笔的种类：黑色主墨、蓝色辅助线、红色强调、黄色荧光笔，四种。
- 具体写法以字形库实际支持的符号为准（根号、上标、乘号若缺字就换写法），出图后逐行目视检查。

界面层：底部居中的带文字主栏，右下的白板翻页控件；形状面板作为第三层叠在左下（见风险）。

## 4. 页面接入

- `SectionScenes.vue`：有成品的卡片渲染 `.nh3-stage`，没有的仍用 `MediaSlot` 占位。层的清单（文件名、位置、宽度、出场方式）写成组件内的常量数组，模板用 `v-for`。
- 图片地址走现有的 `asset()`（带 CDN 回退），深浅色用 `useDarkMode()` 切换，与 `SectionAbilities.vue` 的做法一致。
- 图片是装饰性的，`alt` 为空；面板本身带 `role="img"` 和 `aria-label`（沿用 `scene.media` 文案）。
- 窄屏沿用现有规则（画面在上），层的比例不变。

## 5. 出场动画

复用 `appear.ts`，不新增机制：每一层标 `data-nh3-item`，跟在卡片本身之后依次出现。

- 顺序：卡片 → 内容层（上移＋淡入）→ 墨迹层（仅淡入，位置不动，避免和内容层错位）→ 界面层（上移＋淡入，主栏最后）。
- 需要在 `home.css` 里给“仅淡入”加一个取值；其余用现有的上移。
- 只触发一次，不跟随滚动；系统开启“减少动态效果”时直接显示（`appear.ts` 已处理）。
- 层数多时把组内间隔调到 120 ms 左右，整段在 1 秒内结束。

## 6. 取舍与风险

- **图形不是形状工具画的。** 棱锥用渲染器的 `path` 直线段画，是真实 Inkeys 墨迹，但不是软件“形状”功能的输出；线条两端会有笔锋。样张评审时一并看是否可接受。
- **形状面板只能显示“常规”页。** 渲染器的可点击目标只有主栏和笔属性，切不到“3D”页，面板上选中的是正多边形，与画面里的棱锥不完全对应。样张里先放上，评审时决定保留、换成笔属性面板或去掉。
- **“合并式、大尺寸”没有开关。** 渲染器的 schema 里没有这两个选项，默认输出就是单个“Select”按钮、带文字标签的主栏；按默认输出使用，样张评审时确认是否就是要的形态。
- **小字可读性。** 已知句点偏像短斜线、个别字号下 `w` 一般；推导里避开句点，出图后目视检查。
- 回退：页面改动集中在 `SectionScenes.vue` 和 `home.css` 的新增规则，素材是新增文件，撤回即恢复占位。

## 7. 样张评审后的修订（2026-11-24）

- **线条改用原始采样点。** 图形、直线、虚线、下划线和箭身不再用 `path` 元素（它抬笔时笔还在动，线尾必然出锋，也没有停留收笔的开关），改为在 `build.py` 的 `pace()` 里生成带时间的采样点，用 `stroke` 元素回放：按曲率定速（弯处慢、直线快），起笔由慢到快，收笔减速到峰值的 0.15 倍后在终点停留约 130 ms 再抬笔，线尾是圆的。只有箭头的两撇、圈注和勾保留出锋。`plan` 不覆盖 `stroke`，脚本自己核对最后一个采样点的时刻。
- **另外两张的内容层是图片。** 报告页和幻灯片由 `build.py` 用 Pillow 按 2 倍绘制后缩小，深浅色各一张；墨迹的位置由同一份脚本按文字宽度算出来，所以能对准具体的字和柱子。数据自洽：全年 482（各月之和）、同比 +38%（349 → 482）、月均 40；周活 6,240 → 12,480（八周翻倍）、距 15,000 还差 2,520。
- **界面层。** 屏幕演示用带笔属性面板的主栏；会议与演讲用 PPT 翻页控件加主栏；白板不放形状面板。
