# UInk 1.1 规范正文与样例

> 父任务：`11-24-uink-1-1-spec`。状态：规划中（2026-11-24）。格式设计以父任务 `design.md` 为准，本任务负责把它写成文档、样例与单文件规范。

## Goal

把 `docs/standard/**` 原地升级为 UInk 1.1 Beta 文档：语言对人类和 Agent 都易懂，每个字段标注等级，每个页面写清回退方式；配套 1.1 公开样例、等级检查清单与单文件规范。

## 已确认的决策（2026-11-24）

| # | 决定 |
| --- | --- |
| S1 | **原地升级**：`docs/standard` 直接改写为 1.1。1.0 全文存成一份单文件（`/standard/uink-v10/spec.md`），1.0 样例保留在 `uink-v10/`；另写一页“1.0 → 1.1 变更”，其中包含 1.0 勘误。 |
| S2 | **以 Beta 发布**：Inkeys 与 ICC-CE 完成适配、样例互通验证后再冻结为正式版。冻结后的不兼容修改必须提升版本号。 |
| S3 | **等级认证采用自证**：每个等级分别提供读取与写入检查清单，配套公开样例与期望结果；软件自行验证后声明等级（例如“读取：标准级；写入：基础级”）。不提供自动化测试工具。 |
| S4 | **样例由仓库内的生成脚本产生**：从可读的描述文件生成 `.uink`、`.uink.extra` 与 `fixtures.json`。 |
| S5 | 图形预设的 `construction` 使用**命名字段 Map**：只写对该预设有意义的键，点用 `{x, y}`，未知键忽略，缺少的键用附录缺省值。Inkeys 的 v7 结构需转换。 |
| S6 | 图形预设名称使用**小写短横线**，例如 `regular-polygon`、`legacy-dashed-line`。 |
| S7 | 15 个公开样例**定稿**（2026-11-24）。期望结果尚未经过任何读取器实现验证；Inkeys 适配 1.1 时顺带验证，发现问题再修正样例或规范。 |

## Requirements

- 实现父任务 `design.md` 中的全部线格式变更、分级矩阵与回退规则（D1–D19）。
- 每个块页面采用统一结构，字段表增加“等级”列，并有“回退”一节。
- 新增页面：快速开始、分级与认证、兼容与回退（含兼容导出）、资源包、笔尖与端帽、图形预设注册表（完整级附录）、术语表、1.0 → 1.1 变更。
- 给 1.0 Beta 发布勘误：同主版本向前读取规则。
- 构建时生成当前版本的单文件规范与 `llms.txt`。
- 为可视化子任务预留图示位置（在页面中标出每张图的意图）。
- 不改动与本任务无关的工作区修改。

## Out of Scope

- 可视化图示与交互组件（`11-24-uink-1-1-visuals`）。
- 主页（`11-24-uink-1-1-homepage`）。
- UInk 读写库、自动化测试工具。
