重制三组八段功能演示，让观众在可信的网页、放映和白板环境中，按“指针操作 → 真实控件响应 → 功能结果 → 重点停留”的顺序理解 Inkeys3 的教学价值。保留真实 UI3 / Draw3 渲染和可重建模板，解决旧版主栏无关上浮、焦点竞争、背景归属不清、缺少光标因果、无意义椭圆和烘焙文字等问题。

## Requirements

### R1 场景与核心价值

- 保留三组八幕：屏幕批注（动态、穿透、定格）、课件联动（随页墨迹、动态绑定、开箱即用）、多页白板（背景、分页）。
- A 用同一单摆形成连续教学叙事；B 用立体几何和不同窗口形成连续叙事；C 用三色分屏 → 激光 → 多页书写形成连续叙事。
- 片长由内容决定：A3 约 10 秒、B1 约 9 秒，其余约 6.5–8.5 秒，不为了沿用旧 7 秒而压缩关键教学动作。

### R2 视觉层级与背景归属

- 屏幕批注使用完整浏览器窗口；课件使用可区分身份的放映窗口和桌面空间；白板使用真实全屏主题。
- 外部背景、真实产品控件、真实墨迹/Shape/Laser、宣传片光标、编辑符号和镜头层必须可分辨。
- 删除无意义椭圆、全画面泛光圈、与业务无关的装饰运动。
- 主栏不做模板化上浮或无关入场；需要特写时移动镜头，不把产品控件拖到画面中央。

### R3 光标与点击因果

- 画布外统一使用现代圆角鼠标箭头；自由笔画布内使用真实 PenIcon；穿透/选择状态由下层窗口接管箭头。
- 现代箭头参考用户图一：圆角、深青填充、浅描边和克制的青绿光晕。它是宣传片输入层，不冒充系统默认资源。
- 浅色背景中的 PenIcon 使用深石墨外轮廓并保留笔色填充；深色背景保留对比轮廓。此处理不得宣称为现有用户配置。
- 每次镜头内点击必须有移动、悬停、Down、Up 和结果；指针、原生按压帧与业务状态共用时间轴。
- Shape、Laser、Eraser 等使用真实工具光标，不一律套用自由笔 PenIcon。

### R4 A：屏幕批注教学

- 动态：单摆持续运动，在最低点添加短横线和切向箭头，证明墨迹独立于运动背景。
- 穿透：明确展示 PenIcon → 现代箭头 → 真实穿透按钮 → 下层网页按钮；网页内容切换而批注保持屏幕坐标。
- 定格：在单摆右侧最高点释放定格按钮，背景停住后继续绘制 `mg`、`T`、`Fₜ` 与虚线平行四边形。
- `Fₜ` 必须表示重力的切向分力，不得画成与重力、拉力并列的第三种独立力。

### R5 B：课件联动教学

- 随页墨迹：背景已有部分长方体/圆锥；新增可见辅助线为青蓝实线，隐藏边和构造线为橙黄真实 Dashed。必须包含圆锥后侧虚线弧，并验证返回第 1 页后原辅助线恢复。
- 动态绑定：同时呈现可识别的 PowerPoint 与 WPS 窗口，通过点击另一窗口切换焦点；不要求完整复制 Office 界面，但应用标识、窗口风格、内容和页状态必须不同。
- 开箱即用：使用“安装程序/插件拼图 + 禁止斜杠”和“链环连接 + 确认”符号表达无需安装/插件并直接联动；随后立即完成一笔。不得伪造安装进度、COM 修复或系统成功弹窗。

### R6 C：三色分屏、激光与多页

- 保留白色空白、米白点阵、墨绿网格三个斜向区域，分别来自真实 Whiteboard 主题像素。
- 激光用同一次 contact 连续画一条横向波浪穿过三个区域；使用真实白热核心/彩色光晕，默认不启用粒子。
- 抬起后保留约 1 秒满亮 Hold，再用约 0.8 秒真实 Fade；激光消失后才进入统一斜向转场。
- `board-backgrounds` 的最终构图与 `board-pages` 开场衔接；多页镜头必须包含第 1 页书写 → 第 2 页不同内容 → 返回第 1 页原笔迹。

### R7 镜头与统一转场

- 使用统一 `/` 斜轴、非线性缓动和短距离平移；下一内容向左上，返回沿同轴反向。
- 转场约 0.32–0.44 秒。只在信息空间变化时使用，不用连续推拉代替叙事。
- 点击、定格、翻页提交和笔迹书写期间镜头锁定；关键结果至少保留约 0.8–1.2 秒阅读时间。
- 产品状态变化保持真实时机；斜向平移属于宣传片背景/镜头层，不能冒充原生页面动画。

### R8 文字与 i18n

- 删除合成器写入的宣传标题、教学句段、背景名称和兼容性说明；网页现有标题/说明继续承担文字表达。
- 真实软件短标签、页码由原生 i18n 渲染，不在合成器写死。
- 视频内允许跨语言物理/数学符号（如 `mg`、`T`、`Fₜ`）和应用图标；不得添加需要翻译的句子。
- 安装/插件禁止符号、链环和应用标识必须标注为宣传片层，不冒充产品弹窗。

### R9 真实性与原生边界

- 主栏、分页、真实主题、笔迹、Shape、Laser 和 PenIcon 必须来自生产渲染路径及明确的离屏 fixture，不用网页仿制品替代。
- 当前 `feature/shape` 的虚线、立体图形、光标和 Laser 生命周期按 `research/media-redesign-native-evidence.md` 执行；不宣传自动拉直、任意吸附或持久激光墨迹。
- Freeze 不得出现在 PPT/Whiteboard 的可用状态；课件主栏必须使用正确场景投影。
- 离屏合成不得被描述为 PowerPoint / WPS / VSTO / COM 的端到端验收。

### R10 输出与网页合同

- 主时间轴按 60fps 制作；网页输出桌面 1440×640、手机 720×720 的静音 H.264 MP4，保留 WebP poster 和 README GIF。
- 使用 2 倍超采样保证窗口、光标、虚线和数学符号边缘清晰；最终网页分辨率不盲目增大。
- 每段提供独立时长和首末帧；手机按同一世界坐标重新构图，不直接缩小桌面。
- 沿用现有近视口加载、暂停、隐藏/离屏时钟、手动选择、失败 poster 和清理行为；系统 reduced-motion 不关闭这一明确展示。
- 正式产物必须实际解码验证，不能以进程退出码或文件存在代替完整媒体核验。

### R11 可重建与 token 成本

- 源场景、逐镜头时间轴、素材清单、原生 provenance、导出脚本和验证继续保存在 `media/inkeys3-features/`。
- 优先扩展现有 Python/Pillow + FFmpeg + native offscreen 工具链，不引入 After Effects、Blender、Remotion、OBS 或新 npm/pip 依赖。
- 先输出代表帧和低成本运动试片，批准风格后再批量导出；支持按 scene 重建，避免每次重做全部 60fps 成品。
- 复用共享窗口、单摆、光标、转场和图形构件；调研、native、合成、浏览器验收使用范围明确的上下文，避免重复读取整个仓库。

### R12 工作区与发布边界

- 不启动普通 GUI，不修改用户 Office/COM 配置，不自动 commit/push，不碰无关草案。
- 新原生输入和预览先写入独立目录，保留旧 sources/public 成品作为回滚基线；新成片验收前不覆盖旧公开成品。
- 临时 native 适配必须字节级可恢复并检测并发修改；不得还原用户的新改动或未知构建产物。

- [ ] AC3（R3）：所有镜头内点击都有现代箭头或工具光标的完整轨迹和 Down/Up；按钮状态与业务结果同步，穿透后光标归属正确。
- [ ] AC4（R4）：单摆运动中批注、穿透后网页可操作、最高点定格受力图均可观察；虚线平行四边形和 `Fₜ` 的物理关系正确。
- [ ] AC5（R5）：长方体/圆锥新增线型和颜色明确，圆锥后侧弧为真实虚线；返回原页恢复；PowerPoint/WPS 窗口可区分；开箱即用无伪造安装或 COM 修复。

- [ ] AC7（R7、R8）：全部编辑转场使用统一斜轴；视频无新增宣传句段，原生文字来自 i18n，只有必要数学符号与图标。

- [ ] AC9（R10）：正式媒体为 60fps，尺寸、时长、首末帧、alpha、文件 hash 和完整解码通过；网页实际播放、暂停、换幕和移动端构图通过。

- [ ] AC11（R12）：旧素材在新成片验收前保持可回滚；native 源文件精确恢复；无普通 GUI、Office/COM 配置修改、自动提交或无关文件改动。
