## 设计

- 延续网站青绿、石墨、纸白色，使用有明确浏览器边界的教学画面。让单摆覆盖主要画面高度，减少无意义边距。
- 叙事：大幅运动建立动态背景 → 鼠标悬停并按下真实定格按钮 → 最高点 Up 后背景停止 → 镜头在无输入阶段收紧受力区域 → 真实 Shape 实线及虚线逐步展开 → 保持结果供阅读。
- 固定工具栏锚点，原生按压与业务提交对齐；不把工具栏做成独立漂浮装饰，不把后期镜头当成软件能力。
- 保留 `mg`、`T`、`Fₜ` 数学符号。Fₜ 是 mg 的切向分量，虚线平行四边形以 mg 为对角线。不给视频添加需要翻译的标题或段落。
- 复用 `sources-redesign` 中真实的 UI3 / Draw3 序列，校验 SHA256 与统一画布；不用蒙版伪造原生书写。实际素材不足时先修正分镜，不编造能力。
- 桌面 1440×640、手机 720×720、60fps、静音 H.264；手机单独取景。时长以可读叙事为准，预期 11–14 秒。
- Remotion 依赖和锁文件独立在制作项目，官网只消费最终视频。遵循已安装插件的 create / markup / render Skills。
