## 2. 页面结构

正文用 Markdown 写；只有首屏和分级演示是 Vue 组件。

```
① 首屏  <UInkHero/>
   标题「一份墨迹，处处可读。」
   说明：UInk 是开放的墨迹文件规范。一整块白板、一整份 PPT 的批注，
         只需要一个 .uink：多页、多屏、图片与 PDF 都收在里面。
         换一款软件打开，每一笔都在原处。
   按钮：[阅读规范 → /standard/intro]  [下载样例 → 公开样例]
   主视觉：.uink 文件展开 → 白板页 / PPT 幻灯片 / 图片 / PDF → 收回

② 通用：同一个文件，在不同软件里打开  <UInkTierDemo/>
   一页课堂板书，顶部分段按钮：核心 · 基础 · 标准 · 完整 · +Inkeys。
   切换后画面按回退规则变化，下方一句话说明该级保证什么：
     核心   笔迹与基础图形都在原处；荧光笔不透明，虚线画成实线，箭头没有端头
     基础   荧光笔半透明、矩形笔尖；虚线与箭头；页面点阵背景
     标准   插入的图片出现
     完整   PDF 讲义页出现
     +Inkeys 橡皮生效，被擦掉的字消失
   → 链接「分级与认证」

③ 集合：一块白板，一个文件（Markdown + 静态 SVG）
   一张拆解图：白板 / PPT → 页面 → 屏幕 → 图层 → 图片与 PDF。
   两个场景各一句：白板的所有页、PPT 的每页批注（跟着幻灯片走）都在同一个 .uink。
   → 链接「墨迹主文件」

④ 使用 UInk 的软件（CardGrid + LinkCard）
   Inkeys、ICC-CE：名称、一句话简介、项目链接。

⑤ 开始实现（Markdown）
   三步：读 Header → 按 Canvas 分页 → 绘制 Ink。
   入口卡片：规范正文 · 分级与认证 · 公开样例 · 单文件规范（给 Agent 的 llms.txt）。
```

## 3. 组件

| 组件 | 位置 | 说明 |
| --- | --- | --- |
| `UInkHero.vue` | `docs/.vuepress/theme/components/UInk/` | 标题、说明、按钮、文件展开动画（SVG + CSS） |
| `UInkTierDemo.vue` | 同上 | 分段按钮 + 一幅 SVG 板书；每个元素标注它在哪一级出现 / 变化 |

- 在 `client.ts` 中注册，做法与 `NewHome3` 相同。
- 颜色与字体引用与 `NewHome3/home.css` 相同的数值；不修改 `NewHome3`。
- 组件写成可复用的形式，规范正文的“分级与认证”页可以直接嵌入 `UInkTierDemo`。

## 4. 动效与无障碍

- 不使用滚动进度驱动的动画。首屏动画在进入视口后按时间循环播放，提供暂停按钮，离开视口时暂停。
- `prefers-reduced-motion`：首屏直接显示展开后的静态画面；分级切换不做过渡。
- 分段按钮使用 `role="radiogroup"`，支持键盘左右切换；SVG 提供 `aria-label` 和文字替代说明。
- 深浅色两套配色都要检查。
