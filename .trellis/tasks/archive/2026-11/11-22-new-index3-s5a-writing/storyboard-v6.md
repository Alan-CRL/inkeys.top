# S5-A 分镜（第六版画风）

2026-11-22。画风以 `style-v6.md` 与 `S5A-V6-*` 五张样张为准（用户确认“完全达标”）。
内容、顺序、三语文案沿用 `handoff.md` 第 7 节。

## 0. 规格

| 项 | 取值 |
|---|---|
| 画幅 | 2520×1080（21:9），60 FPS，1800 帧 = 30 秒，第 1800 帧等于第 0 帧 |
| 安全区 | 文字和关键墨迹放在 x 396–2124；卡片可以出画 |
| 声音 | 无声 |
| 语言 | zh-CN 先做，zh-TW、en-US 只换字；英文标签两行、字号约 130（中文 200） |
| 墨迹 | `src/s5a/ink/draw3Ink.ts`（软件 Draw3 链路模拟）；主墨黑/白，特征色青，青色段圆头起笔盖住主墨 |
| 镜头 | 摄影机不动；动的是卡片（倾斜、转正、放大）和字 |

## 1. 镜头语法（每种全片只当一次主角，转场语法除外）

| 用途 | 借用的镜头卡 | 改动 |
|---|---|---|
| 幕标题“C++ · Direct3D · HLSL” | `lead-word-zoom-assemble` | 三个词先在正中依次弹出、互相替换，最后一起归位成一行 |
| 幕标题“120+ FPS”“软笔” | `blur-slide` | 逐词上浮去模糊入场；“软笔”落定后字面掠过一道亮光 |
| 每幕第一个功能的开场 | `title-demote-to-label` | 大字不缩成小标签，保持大字号滑到卡片一侧；卡片同时从字后升起并倾斜 |
| 同幕后续功能 | `blur-slide` 换词 | 侧边大字先换成新功能名（约 0.3 秒），然后卡片才动，字始终领先画面 |
| 多层画布 | `cloner-depth-echo` | 7 个分身改为 3 层：点阵层、已写好的墨、正在写的笔尖，沿纵深错开再吸回 |
| 墨迹预测、实时笔锋 | `speed-ramp-freeze` | 只借变速：放慢到约 0.25 倍再恢复；不定格、不加圈注 |
| 多指书写 | `collab-cursor-moves · cast-ensemble` | 四个画笔光标错峰进场，各自写各自的 |
| 明暗切换（3 次） | `shot-transitions · mask-wipe` | 一张新主题色的卡从画面下方升起、放大铺满，成为下一幕的底 |

其余（局部刷新、快细慢粗、手抖修正、抬笔修正、结尾写字）为专门新写。

## 3. 时长与平衡

- 暗场约 17 秒，亮场约 13 秒（切换各算一半）。
- 幕标题 3 个共 4.1 秒，功能开场 3 个共 1.2 秒，九个功能共 20.1 秒（平均约 2.2 秒），明暗切换 4 次共 1.9 秒，结尾写字加停留 2.7 秒。
- 每段关键信息落定后都留了 0.3–1.0 秒的停顿；结尾字标停 1 秒。

## 4. 待确认

## 5. 用户确认与实现调整（2026-11-22）

- 第 4 节三项用户均同意。
- 实现时按 lead-word-zoom-assemble 的原参数（换算到 60fps）给开幕字留出归位与停顿，开幕字延长到 2.2 秒，第一幕后续镜头相应顺延，总长不变。
- 第二幕“墨迹预测”改用绕着刚才几圈画的一个大外圈，避免特写里与旁边几圈平行挨着；“多指书写”与第三幕各功能通过平移白板换到新的空白区域，不清屏。
- 时间以 `media/nh3-remotion/src/s5a/film/timeline.ts` 为准。
- 自检后调整：“快细慢粗”延长到 20.90–23.10 秒（S 形一笔约 1.7 秒），“手抖修正”改为 23.10–24.70 秒；开幕字的测量改为整行从第一帧起挂载。预览方式：只开 Remotion Studio，不渲染整片。
