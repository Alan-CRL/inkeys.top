# S5-A 第七版修改计划（内容调整）

2026-11-23。画风沿用第六版（用户确认样式满意），本轮改内容和细节。确认前不动代码。

## 0. 对软件行为的理解（来自 Draw3 源码）

`Draw3.DrawingController.cpp` 的 `CompositeLayersToBackBuffer(dirty)`：每一帧只处理一块**脏区矩形**——先把 L2 在这块区域拷进后台缓冲，再把 L1 和 L0 **合并**（`ApplyActiveOperatorLayers`，CoverageUnion）盖上去，最后在最底下补白板点阵。

| 层 | 内容 | 生命周期 |
|---|---|---|
| L2 | 已经抬笔的墨迹 | 稳定的底层画布；抬笔时本笔整笔并入 L2 |
| L1 | 正在写的这一笔里已经“烘干”的前缀 | 书写中逐段累积；抬笔后清空 |
| L0 | 笔尖：实时笔锋 + 墨迹预测 | 每帧清空重画 |

所以片子里的“局部刷新”应当是：L1 与 L0 合成一层，只有笔尖周围那块脏区被重新合成到 L2 上（用柔光表示这块区域），其余画面不动。

> 你原话写的是“L1 和 L2 合并”，按上表我理解为 **L1 和 L0 合并**，见第 5 节问题 1。

## 2. 墨迹内容：不再用 sin x 和正弦

- 板书、算式、解题步骤都用同一套单线手写字形来写，每个字形都走 Draw3 墨迹模拟；每个字加少量随机倾斜、大小和间距变化，避免整齐得像印刷体。
- 字形来源：现有的手写字形库只有 `I n k e y s x h =` 等十几个，写不满一页。我打算用开源的单线矢量字体（Hershey 系列，或 EMS 的 SVG 单线字体，SIL OFL 许可）作为骨架，覆盖数字、字母和 `= + − ( ) √ ²` 等符号。见第 5 节问题 2。
- 内容用语言无关的数学解题过程（类似图二），三种语言版本共用；还会画一个小几何图，让板书更像真实课堂。
- 各镜头的笔画：
  - 多层画布、局部刷新：在板书下面续写一行算式，或圈出答案。
  - 超低延迟、墨迹预测：保留快速画圈和外圈（你认可过）。
  - 实时笔锋：长弧线箭头。
  - 快细慢粗：连笔线圈。
  - 手抖修正：慢速下划线。

## 3. 细节修正

1. **`HLSL` 高度不一致**（约 1.00 秒）：`C++`、`Direct3D` 在替换阶段比最后成行的 `HLSL` 低约 75px。原因是替换阶段和成行阶段用了两套排版：一个按单个词居中，一个按整行居中。修法：替换阶段的词改用整行的基线定位。
2. **`FPS` 的 S 右下角缺块**（约 8.10 秒）：逐字渐变的背景宽度按测量的行宽设置，比 S 实际的字形外沿窄，右下角没有被填上。修法：渐变背景两侧各放宽一段，再按原偏移对齐。
3. **墨迹速度顿挫**（约 20.30 秒和 22.00 秒）：`paced()` 在快、慢之间切换太硬。改为对速度本身做平滑（速度曲线连续，加速度有上限），同时保证慢段仍然够慢，能出粗细。
4. **起笔粗头、出锋停顿**（约 20.30 秒）：
   - 起笔不再从很慢开始，粗头就不会比笔身更粗。
   - 收笔时笔保持原速离开，不在末端减速停住，模型里的实时笔锋才能自然收尖。
   - 按你的建议改用细笔（基准宽度约 20，原来是 74），把视图放大约 2 倍，画面上的粗细基本不变，笔锋比例更接近软件。

## 6. 实现调整（2026-11-23）

- 总长 1854 帧（约 30.9 秒）。快细慢粗的线圈要慢到约 150 才粗得明显，一笔约 2.1 秒，所以把这段加长了 0.3 秒。时间以 `media/nh3-remotion/src/s5a/film/timeline.ts` 为准。
- 多层画布：三层分开时卡片后仰约 52°，各层沿卡片法线拉开（`Board` 新增 `spread`），读起来像爆炸图；抬笔后这一笔从 L1 的高度落进 L2。

- Patrick Hand 的中心线由 `media/nh3-remotion/scripts/patrick-centerlines.py` 提取，生成 `src/s5a/film/patrickHand.ts`。字体文件放在 `.cache/fonts/patrickhand/`，不入库。手写排版时做了三处修正：

  - 小字号下 `M` 像 `H`，板书内容里不用。

## 7. 第二轮修改计划（2026-11-23，用户反馈后）

1. **多层缓冲**（原“多层画布”）：
   - 侧边字改为“多层缓冲 / 多層緩衝 / Layered buffers”。
   - 卡片倾斜退回第六版的程度（约 7°/16°），三层沿右上方错开，不再后仰成爆炸图。
   - 从卡片升起到切到下一幕，只写**同一条长墨迹**，一直不抬笔，视图跟着笔尖走。
   - 顺序：三张（L2、L1、L0）→ 两张（L2、L1+L0），侧边字换成“局部刷新”，高光在 L1+L0 这一张上跟着笔尖 → 两张合成一张，高光继续跟着笔尖走一段，然后转场。
2. **板书字形**：
   - 小字粗细不匀、字形变形的原因有三：
     - 弯处、起笔处减速，Draw3 按速度加粗；
     - 每笔都加了 55ms 的收尖；
     - 弹簧平滑滞后约 17px，把 `6` 的小圈抹掉了。
   - 实现：板书小字改为沿字形中心线直接成墨，匀速、粗细恒定。
   - 根号改为数学写法：左侧小勾、下折、上挑、顶横一笔连写，转角圆顺，横线盖住根号里的数。
3. **脏圈**（约 26.30 秒）：是连笔线圈圈顶的内孔。慢段笔宽变粗后，孔被墨填得只剩一个小椭圆。线圈放大，让内孔明显张开。
4. **主栏**（约 13.20 秒）：推近时主栏改为固定在白板上，随白板一起放大、跟着内容走，移出画面后就不再出现，预测特写里没有主栏。
5. **预测段跳变**（约 14.30 秒）：原因是墨尖和预测末端都取离散的输出点（每秒 360 个），慢放时每帧在相邻点之间来回取整，预测段长度一跳一跳。改为按精确时刻在相邻点之间插值，墨尖和预测末端都连续前进。
