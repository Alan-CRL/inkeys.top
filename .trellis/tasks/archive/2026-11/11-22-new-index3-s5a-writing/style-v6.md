# S5-A 第六轮样式方案（文字稿）

2026-11-22。依据：用户本轮的样式说明 + 五张参考图（图 1–3 开幕字的类型，图 4 卡片轻微倾斜，图 5 卡片配大字）。
内容、顺序、三语文案不变，见 `handoff.md` 第 7 节。

## 1. 两种场景，按幕交替

一支视频同时用在深、浅主题的网页里，所以片内亮场和暗场交替，时长大致对半。

| | 亮场 | 暗场 |
|---|---|---|
| 背景 | 纯白 `#FFFFFF`，无纹理 | 近黑 `#08090A`，一角漫进一团深青绿 `#0E3A36`（呼应网页板面的山林绿），大面积仍是黑 |
| 大字 | 横向渐变：`#006A63 → #0FA396 → #4CC6D6`（网站品牌青的明暗两端） | 纯白；落定后可有一道慢速掠过字面的亮光，只在字内，不向外发光 |
| 点阵卡 | 白卡，点为 18% 黑（与软件白板同规格：24 间距、1 半径），1px `rgba(0,0,0,.06)` 描边 + 一层很淡的大投影 | `#121416` 卡，点为 18% 白，1px `rgba(255,255,255,.08)` 描边，顶边一线很淡的内高光 |
| 主墨 | 墨黑 `#15171A` | 白 `#F4F4F2`（软件深色白板默认就是白墨） |
| 特征色 | 青 `#0A9C90` | 青 `#58FFEC`（网站深色主题强调色） |

每个场景只有三样颜色：底、主墨、特征色；特征色与大字渐变同一色相，全片一套。

## 2. 三种镜头

1. **开幕字**（每幕开头，约 1 秒）：词一个接一个在正中弹出、互相替换（如 C++ → Direct3D → HLSL），最后并排停一拍。字体沿用网站字体栈：Segoe UI Variable Display / 微软雅黑 UI，粗体，字很大。
2. **功能开场**（每个功能前，约 0.5 秒）：功能名先在正中以大字出现，随后点阵卡从字后升起并轻微倾斜（像图 4），字同时滑到卡片一侧保持大字号（像图 5），不再缩成底部小字幕。卡片可以出画（被裁掉无妨），文字留在 21:9 的中间安全区内。
3. **点阵卡演示**：卡片有边界、不铺满画面，卡底挂软件真实主栏（原生导出图，深浅两版现成）。镜头不动，卡片自己倾斜、转正、放大。看细节时卡片转正并放大到局部。光标是 Inkeys 画笔光标，贴在卡面上。

## 3. 墨迹是主角：每个功能怎么表达

| 功能 | 画面 |
|---|---|
| 多层画布 | 三张卡沿纵深错开悬着（点阵层、已写好的墨、正在写的笔尖），随后合成一张 |
| 局部刷新 | 笔尖附近的卡面有一团柔光，那段墨更亮，像湿墨反光；其余部分静止 |
| 超低延迟 | 快速书写，光标与墨尖始终重合 |
| 墨迹预测 | 放大到笔尖，光标前面一小段墨用特征色（纯色，不渐变），墨持续往前走，光标到达后变回主墨 |
| 多指书写 | 几个光标同时写，各出各的笔迹 |
| 实时笔锋 | 放大，最前端正在收细的那段是特征色，定形后变回主墨 |
| 快细慢粗 | 一笔里快处细、慢处粗，卡片放大看粗细变化 |
| 手抖修正 | 一条浅灰的抖动线，墨沿它写出来却是顺的 |
| 抬笔修正 | 抬笔瞬间，末端收成干净的笔锋 |

## 4. 明暗分配与切换

- 第一幕（C++ · Direct3D · HLSL、多层画布、局部刷新）：暗场。
- 第二幕（120+ FPS、超低延迟、墨迹预测、多指书写）：亮场。
- 第三幕（软笔、实时笔锋、快细慢粗、手抖修正、抬笔修正）：暗场。
- 结尾写出 Inkeys：亮场，接回开头的暗场。
- 暗转亮：一张白卡在暗场里升起、放大铺满画面，成为亮场的底（约 0.4 秒）。亮转暗同理用暗卡。不做全屏白闪，不硬切明暗。

## 5. 明确不做（避开前几轮的失败和“AI 味”）

发光光晕、镜头光斑、漂浮光斑和粒子、彩虹或渐变边缘光、霓虹描边字、噪点颗粒、给功能加框加圈加切线、实体笔、拟物桌面玻璃、摄影机 3D 运镜、一个场景里超过三种颜色。

## 6. 用户确认（2026-11-22）

- 墨色：中性主墨 + 青色特征色（用户选定）。
- 明暗按幕交替：用户未提异议，样张阶段继续观察。

确认后出 4 张 2520×1080 样张：暗场开幕字、亮场功能开场（大字 + 倾斜点阵卡 + 主栏）、亮场墨迹预测特写、暗场实时笔锋特写。
