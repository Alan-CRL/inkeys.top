## 1. 全页骨架

### 1.1 节奏

页面只有两种区块，交替出现：

- **居中、留白大的区块**：S0 首屏、S1 标题段、S5-A、S6。字少，四周空，用来停顿。
- **左对齐、内容密的区块**：S2、S5-B、S7、S8、S9。标题靠左，内容铺满栏宽，用来阅读。

S6 是全页的分界线。S6 之前是主线（看完就该想下载），区块标题用大标题 `t-display`；S6 之后是给还想多看的人准备的，区块标题降一级用 `t-title`，区块间距也收紧，让人一眼看出“主要内容已经结束”。

### 1.3 栅格与通用规则

- 内容栏 1200，分 12 栏，栏间距 24；左右边距 `clamp(20px, 5vw, 48px)`。
- 区块间距（上一块底到下一块顶）：主线 `clamp(96px, 12vw, 176px)`；S6 之后 `clamp(72px, 9vw, 128px)`。
- 标题到导语 24；导语到下面的内容 `clamp(48px, 6vw, 72px)`。
- 文字宽度：大标题最宽 18em（中文约 18 个字），导语最宽 34em，卡片里的正文最宽 30em。超出就换行，不缩字号。
- 页内跳转的目标都设 `scroll-margin-top: 88px`，避免被顶栏盖住。

### S0 首屏

```
 ----------------------------------------------------------------------
  [碎片 屏幕批注 4:3]                              [碎片 自由白板 4:3]--> 伸出
                                                                     
                         I n k e y s                   [碎片 多样笔触]--> 伸出

               让每一次操作都赏心悦目。

  [碎片 主栏 5:2]                                  [碎片 PPT 演示 4:3]--> 伸出
                                                            (样式)(暂停)
 ----------------------------------------------------------------------
```

**布局**

- 高度 `100svh - 64px`，内容整体垂直居中，再向上偏 24，给下方按钮留出呼吸。
- 中间 60% 的宽度是保留区，只放艺术字、标语和按钮，碎片不进入。
- 艺术字画布的尺寸和位置沿用现有实现，不改。
- 艺术字到标语 32；标语到按钮 32；两个按钮间距 16。按钮一行放不下时整体换行，各占一行并居中。
- 碎片五张：左上、左下、右上、右中、右下。宽 `clamp(150px, 15vw, 230px)`，各自倾斜 3°–4°，右侧三张伸出屏幕边缘 2%–6%。左边两张、右边三张，重心略偏右，和左对齐的后续区块形成呼应。
- 书写控制（样式面板、暂停）在右下角，离边缘 24。
- 1100 以下隐藏全部碎片，其余不变。

**排版**

| 内容 | 级别 | 说明 |
| --- | --- | --- |
| 标语 | `t-lead`，文字色 | 两个分句各包成 `inline-block`，宽屏一行、窄屏在逗号后断开 |
| 立即下载 | 主要按钮 | 高 48 |
| 为 GitHub 点亮 Star | 次要按钮 | 高 48，前面带 GitHub 图标 |
| 碎片名称 | `t-small` | 悬停时出现在碎片下方 10px |

英文标语比中文长约一倍，按两行设计，三行也不挤到按钮。

### S2 从屏幕到讲台

> **2026-11-16 修订（用户看过实现后）**，以下几条覆盖本节后面的旧描述：
> - **取消步骤条和步骤名。** 画面是一段自动轮播的视频，每一步在讲什么由视频里的大字说明，网页上不再有步骤按钮和暂停按钮。
> - **场景名改成标签。** 黑白反色的胶囊（高 30，字号 13，字重 500），和主按钮同一种填充，不可点击，不再用主题色文字。
> - **文字栏上下分开。** 标签和标语顶在上面，说明（和角注）沉到底部，中间留空，不再整体垂直居中。
> - **中间那张卡片左右对调**：画面在左、文字在右。第一、三张仍是文字在左。窄屏三张都是画面在上、文字在下。
> - 卡片高度由 16:10 的画面决定；文字更长时（英文）卡片跟着长高，画面垂直居中。

**布局**

- **步骤条横排在画面正下方**，和画面同宽，四步等分，离画面 12。每步上方是一条 2px 的线，下方是步骤名。这一点和样张不同（样张里步骤竖排在文字栏）：三张卡片的说明都有四五行，再叠上四个步骤，文字栏会比画面高出 150px 以上，画面旁边空出一大块；横排后两栏高度接近，步骤也挨着它控制的画面。
- 文字栏内容垂直居中。
- 880 以下：画面在上，步骤条在画面下方改为两行两列，文字在最下面；卡片内边距仍是 12，文字部分内边距 24。
