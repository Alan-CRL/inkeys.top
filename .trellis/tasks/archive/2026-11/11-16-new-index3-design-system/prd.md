# new-index3 设计语言与页面框架

## Goal

为 `/new-index3` 确定一套统一的设计语言，并按 [content-plan.md](../11-16-new-index3-content-plan/content-plan.md) 重构首屏以下的页面框架。媒体资源（Remotion 视频、原生截图、背景图）本任务一律用占位，不制作。

工作分两步，第二步在第一步确认后才开始：

1. **样式选型**：制作若干风格模板供用户挑选，确认后把规范写成文档。
2. **框架实现**：按选定的规范实现页面框架。

## 背景（用户 2026-11-16）

- 内容规划 S0–S6 已定稿，S7–S9 仍是初稿。
- 风格偏好：Xmind、OpenAI、Anthropic 官网那样的简约风格；首屏背景可以全部纯色。
- 现有内容只保留首屏的艺术字绘制；首屏的按钮样式要调整；首屏以下全部重构。

## 已确认的决定

| # | 决定 | 结论 |
| --- | --- | --- |
| D1 | 主题色 | 青色，已确定：浅色 `#006a63`，深色 `#58ffec` |
| D2 | 字体策略 | 系统字体为主；只有品牌字和拉丁大标题可以加载网络字体，且必须本地托管 |
| D3 | 适用范围 | 仅 `/new-index3`（含该页的顶栏、页脚外观）；其他页面不动 |
| D4 | i18n | 只做版式准备：文案抽成按语言分开的词典，版式能容纳更长的译文；不开通繁中、英文页面的访问路径 |
| D5 | 风格模板 | 选定“纯净”（中性黑白灰、胶囊按钮）；规范见 [design.md](./design.md) |
| D6 | 墨迹展示卡片（S5-A） | 不用高亮色，改用有质感的深墨绿板面 |
| D7 | 首屏艺术字 | 现有的书写动画原样保留，模板里的静态字只是示意 |
| D8 | 主按钮 | 黑白反色，不用主题色作底 |

## Requirements

### 第一步：样式选型

- R1 制作 3 套风格模板，放在同一个可切换的预览页里，每套都能切换浅色／深色和 zh-CN／zh-TW／en-US。
- R2 每套模板用相同的内容展示：顶栏、首屏（艺术字位置、标语、两个按钮）、S1 标题段与三张竖向卡片、S2 的一张平铺卡片（含步骤切换）、S5-A 高亮区块、S6 下载收尾，以及一块规范样张（字号阶梯、按钮各状态、圆角、色板）。
- R3 模板之间的差异集中在：背景与中性色的冷暖、标题字的气质、圆角大小、按钮形状与填充方式、卡片的处理方式、动效的性格。主题色按 D1 固定。
- R4 用户选定（或混搭）后，把规范写入 `design.md`，包括：
  - 色彩：背景、文字、分隔线、卡片填充、主题色及其各状态，浅色与深色各一套。
  - 字体：三种语言各自的字体栈、字号阶梯（大标题到小字）、字重、行高、字间距、换行规则。
  - 形状：圆角阶梯、卡片、按钮（主要、次要、文字链接；默认、悬停、按下、焦点、禁用）。
  - 版式：栏宽、间距阶梯、断点、各区块的留白。
  - 动效：时长与缓动曲线的固定取值、进入视口的出现方式、悬停与按下反馈；嵌入 Remotion 媒体的约定（容器比例、封面图、自动播放与暂停、减少动态效果时的表现、深浅色素材切换）。
  - 交互：步骤卡、轮播、暂停控件、键盘焦点、触摸屏下的悬停替代。

### 第二步：框架实现

- R5 首屏保留艺术字绘制及其书写控制，背景改为纯色，按钮改用新规范，加入“为 GitHub 点亮 Star”次按钮；书写样式面板和暂停按钮挪到不显眼处。
- R6 首屏以下按内容规划重建 S1、S2、S5-A、S5-B、S6、S7、S8、S9 的框架；S7–S9 用初稿内容搭好结构，文案待评审。
- R7 所有媒体位置用统一的占位组件，标明比例和将来放什么；占位组件的接口要能直接换成视频或图片。
- R8 文案集中到按语言分开的词典文件；版式在三种语言下都不溢出、不断出孤字。
- R9 不使用滚动进度驱动的动画；页面滚动保持浏览器原生行为。
- R10 首屏碎片（S0 的 5 张示意图）只留出位置和悬停交互，图片用占位。

## Constraints

- 文案面向普通用户，不出现底层术语和性能数字（沿用内容规划第 0.4 节）。
- 简体中文页面品牌写作“智绘教Inkeys”，其他语言写“Inkeys”。
- 网站访客主要在中国大陆，字体和脚本不能依赖 Google Fonts 等境外地址。
- 遵守 `.trellis/spec/frontend/` 的现有规范。
