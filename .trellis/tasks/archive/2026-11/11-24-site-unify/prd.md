# 全站视觉与内容统一

## Goal

首页（new-index3）和 UInk 首页已经换成新的配色与顶栏样式，其他页面仍是 Plume 默认外观。把这套视觉推广到全站，同时升级 Plume，并顺带优化下载卡片、规范页面文案。

## 子任务

| 顺序 | 子任务 | 交付 |
| --- | --- | --- |
| 1 | `11-24-plume-upgrade` | Plume rc.204 → rc.219 及配套依赖升级，现有页面无回归 |
| 2 | `11-24-site-palette` | 其他页面背景 / 配色改用首页令牌，顶栏按钮与首页统一 |
| 3 | `11-24-download-card` | 下载卡片优化 |
| 4 | `11-24-page-copy` | 规范页面文本，为 `/inkeys3` 写简单介绍 |

先升级再换色：换色以升级后的 Plume 为基准，避免做两遍回归。3、4 可在 2 之后独立进行。

## 整体约束

- Plume 的控件（侧边栏、大纲、提示块、代码块、搜索等）继续使用，只改颜色与顶栏按钮。
- 不复制或替换 Plume 组件文件，只用 CSS 变量、公开插槽和少量类名选择器，保证以后还能升级（见 `research/plume-upgrade-impact.md`）。
- 文案面向普通用户，不堆术语和指标（沿用首页文案偏好）。
- 不使用滚动驱动动画。

## 跨子任务验收

- [ ] 升级后首页、UInk 首页、文档页、版本列表页、下载页在浅色 / 深色、桌面 / 手机下无错位。
- [ ] 首页之外的页面与首页切换时，背景、顶栏不再有明显跳变。
- [ ] `pnpm docs:build` 通过。

## 已确认的视觉决定（2026-11-24）

- 品牌色：全站从蓝色（`#2670e6`）换成首页的青绿强调色（浅 `#006a63` / 深 `#58ffec`）。
- 无界感：侧边栏与内容区同底色；侧边栏、顶栏、页内导航等处的分割线去除或与底色同色。
- 顶栏：全站学习首页——同一套按钮（“下载”按钮、深浅色圆按钮、“更多”菜单），去掉顶栏分割线。
- 搜索：首页以外的页面都保留搜索，外观改成与首页按钮同一风格；首页仍不显示搜索。
